# Recursos web de Akhyles

`akhyles-hero-machines-v1.png` es una imagen horizontal para la portada de la
web: maquinaria contemporánea de fuerza sin personas, marcas ni texto. La
composición deja espacio oscuro a la izquierda para el titular y usa verde
profundo con detalles verde salvia, coherentes con Akhyles.

Uso previsto en IONOS: imagen de fondo de la primera sección de Inicio, con una
capa oscura suave si hace falta para conservar contraste del texto. No sustituye
el icono de la aplicación ni contiene datos de usuarios.
